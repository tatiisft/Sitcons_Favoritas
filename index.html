Sobre o Site

Este projeto foi criado para compartilhar algumas das nossas séries de comédia favoritas, reunindo informações sobre suas histórias, personagens e curiosidades.


Além de conhecer nossas séries preferidas, você também pode explorar um Dashboard interativo com dados de 50 sitcoms, disponibilizados em um dataset do Kaggle.


No Dashboard, é possível comparar avaliações, descobrir os gêneros mais frequentes e analisar as décadas de estreia das séries por meio de gráficos e filtros interativos.
